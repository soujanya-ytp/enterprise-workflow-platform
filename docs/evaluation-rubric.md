# Stack-independent evaluation rubric (100 points)

| Dimension | Points | Evidence |
|---|---:|---|
| Requirements coverage | 20 | Acceptance criteria mapped to working behavior |
| End-to-end functional correctness | 20 | Independent API/UI workflows and test evidence |
| Architecture and maintainability | 15 | Clear module boundaries, readable code, separation of concerns |
| Data integrity and business rules | 15 | Constraints, transactions, valid state transitions |
| Security and access control | 10 | Authentication, authorization, input validation, secrets handling |
| Test strategy | 10 | Unit, integration, negative and boundary tests |
| Operability and documentation | 5 | Reproducible setup, health checks and useful docs |
| Engineering judgment | 5 | Trade-offs, assumptions, limitations and prioritization |

Use the same scenarios and weights across stacks. Do not score on framework preference or code volume alone.
